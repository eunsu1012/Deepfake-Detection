# 🎭 Deepfake Detection using EfficientNetB4 and VGG19

A deep learning project for detecting StyleGAN-generated deepfake face images.  
This study compares EfficientNetB4 and VGG19, each as a base model and with an added dense head, on accuracy, training cost, and inference speed.

📄 **Published at AMLDS 2025 (IEEE), Tokyo, Japan** — [DOI: 10.1109/AMLDS63918.2025.11159417](https://doi.org/10.1109/AMLDS63918.2025.11159417)


## 📌 Overview

Deepfakes are AI-generated images that closely mimic real human faces, posing serious risks of misinformation, fraud, and privacy violations.  
StyleGAN in particular produces highly realistic faces that avoid the visual artifacts of simpler GAN models, making detection difficult.

This project compares a classic deep CNN (VGG19) and a modern efficiency-focused CNN (EfficientNetB4) to find which architecture best suits different deployment needs.


## 🎯 Objectives

- Detect StyleGAN-generated deepfake face images using transfer learning  
- Compare EfficientNetB4 and VGG19 under identical training settings  
- Test whether adding a deeper classification head improves performance  
- Analyze accuracy–cost trade-offs (training time, inference time)  


## 🧠 Key Features

- Binary classification of real vs. fake faces on **140,000 images**  
- **4 models** compared: EfficientNetB4 / VGG19 × Base / Fine-tuned (added dense head)  
- ImageNet-pretrained backbones with identical hyperparameters for a fair comparison  
- Confusion-matrix analysis of a failed augmentation experiment  


## 🗂️ Dataset

**[140K Real and Fake Faces](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces)** (Kaggle)

- **Real:** 70,000 faces from NVIDIA's Flickr dataset  
- **Fake:** 70,000 faces generated by StyleGAN  
- Wide natural variation in age, ethnicity, lighting, background, and accessories  

| Split | Real | Fake | Total |
|---|---|---|---|
| Train | 50,000 | 50,000 | 100,000 |
| Validation | 10,000 | 10,000 | 20,000 |
| Test | 10,000 | 10,000 | 20,000 |


## ⚙️ Methodology

1. Data preprocessing  
   - Resizing images from 256×256 to 224×224  
   - RGB color mode, pixel values normalized to 0–1  
   - No artificial augmentation in the main experiments, since the dataset already has high natural variability  

2. Model Development  
   - **Base models:** ImageNet-pretrained backbone + single sigmoid output  
   - **Fine-tuned models:** backbone + Global Average Pooling + Dense(1024 → 512 → 256, ReLU) with Dropout (0.2 / 0.3 / 0.5) + sigmoid output  

3. Training  
   - Adam optimizer (lr = 0.001), binary cross-entropy loss  
   - Batch size 32, 25 epochs, validation accuracy monitored every epoch  

4. Evaluation  
   - Train / validation / test accuracy  
   - Training time and per-image inference time  
   - Loss curves and confusion matrices  


## 🧩 Model Architecture

### 1. EfficientNetB4
- Compound scaling of depth, width, and resolution  
- ~19M parameters, high accuracy with fewer resources  
- Chosen as the efficiency-focused modern architecture  

### 2. VGG19
- 16 convolutional + 3 fully connected layers with repeated 3×3 convolutions  
- Simple, deep structure that captures fine-grained image features  
- Chosen as a robust classic baseline  


## 📊 Model Evaluation

| Model | Train Acc | Val Acc | **Test Acc** | Training Time | Inference Time* |
|---|---|---|---|---|---|
| EfficientNetB4 Base | 99.80% | 98.30% | 98.54% | **99.6 min** | 0.846 s |
| EfficientNetB4 Fine-tuned | 97.83% | 96.30% | 95.54% | 111.3 min | 0.863 s |
| VGG19 Base | 99.64% | 99.20% | **99.11%** | 327.5 min | 0.190 s |
| VGG19 Fine-tuned | 99.10% | 99.25% | 99.00% | 308.8 min | **0.139 s** |

\* Per-image inference time measured in our training environment.

## 🚀 Results

- **VGG19 Base** achieved the highest test accuracy (**99.11%**)  
- **Adding a dense head did not help:** EfficientNetB4 dropped from 98.54% to 95.54%, likely because the extra parameters reduced generalization; VGG19 changed by only 0.11%  
- **EfficientNetB4 trained ~3× faster** than VGG19 (99.6 vs. 327.5 min), making it suited to resource-constrained training  

**Augmentation experiment:** With augmentation (rotation, shifts, zoom, horizontal flip), one epoch on the full dataset took ~24 hours on a P100 GPU. On a reduced 2,000-image subset, both fine-tuned models predicted **every image as real** (50% accuracy, 0 fakes detected). The confusion matrix exposed this failure, which accuracy alone would have hidden.


## 📌 Limitations

- Only StyleGAN-generated images were tested; diffusion models and face-swap deepfakes were not evaluated  
- Static images only; video deepfakes were out of scope  
- Large-scale augmentation experiments were limited by GPU resources
